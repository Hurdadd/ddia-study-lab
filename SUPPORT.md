# Support

Use a question issue for explanations, a bug report for broken behavior, and a design
proposal for architectural changes. Include page/anchor, language, theme, browser,
viewport, expected/actual behavior and minimal reproduction steps.

Consult README, docs/DEVELOPMENT.md, docs/RECOVERY.md and the relevant ADR first.
For security reports, follow SECURITY.md. The project has no paid support or response SLA.
Maintainer: hurdad ashouri (@Hurdadd).
