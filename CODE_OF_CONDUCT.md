# Code of Conduct

We welcome contributors of all backgrounds and experience levels. Be respectful,
clear and patient. Discuss the work and its evidence rather than attacking people.

Harassment, discrimination, threats, sexualized conduct, doxxing, and disclosure of
another person’s private information are unacceptable. Respect accessibility needs,
credit others’ work, and accept reasoned corrections.

The maintainer, hurdad ashouri, may remove content, request changes, pause a thread,
restrict participation or remove access. Responses should be proportionate, explain
which conduct is at issue, and allow a good-faith appeal to the maintainer.

For a concern, request a confidential contact channel from @Hurdadd without posting
sensitive details in an issue. Use GitHub’s reporting controls for immediate platform
abuse. Do not publish the reporter’s identity or report details without consent.

These standards cover repository discussions, issues, PRs and project-managed spaces.
This is an original project policy, not an adopted third-party covenant.
