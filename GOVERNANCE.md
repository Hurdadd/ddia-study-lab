# Governance

Own the Stack is maintained by **hurdad ashouri** (@Hurdadd).
The maintainer owns release decisions, technical direction, review and conduct
moderation. Contributors retain copyright in their contributions.

Use issues for scoped proposals and ADRs for significant technical decisions.
Record context, alternatives, trade-offs, assumptions, validation and revisit triggers.
Do not delete superseded decisions; link a replacement. Discussion can reopen a decision
when new evidence appears. The maintainer resolves ties and explains the trade-off.

The default branch is `main`. Prefer reviewed PRs; emergency corrections require a
follow-up explanation and checks. Releases describe the educational artifact and its
actual tested behavior, not completion of the proposed platform. Public visibility,
new external services, paid resources and changes to license terms need explicit
maintainer authorization. The website is public by the maintainer’s explicit request; the GitHub repository remains private.
