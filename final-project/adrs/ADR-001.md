# ADR-001 — کاربر اصلی چه کسی است؟

Who is the primary user?

Status: accepted · Date: 2026-10-15

## مسئله / Context

«پلتفرم AI» هم می‌تواند محصولِ توسعه‌دهنده باشد و هم پشت‌صحنهٔ یک دستیار on-call. این دو، نیاز و اولویت متفاوت دارند.

An AI platform can serve developers or sit behind an on-call assistant; their needs and priorities differ.

## گزینه‌ها / Alternatives

توسعه‌دهندهٔ برنامهٔ AI؛ یا مهندس on-call.

AI-application developers or on-call engineers.

## انتخاب فعلی / Choice

کاربر اصلی نسخهٔ اول توسعه‌دهنده است؛ Investigator فقط یک برنامهٔ نمونه روی پلتفرم است.

The initial primary user is an application developer; Investigator is a sample platform application.

## چرایی و trade-off / Rationale and trade-off

دامنهٔ پذیرفته‌شدهٔ این کارگاه، پلتفرمِ قابل‌استفاده‌مجدد برای توسعه‌دهنده است؛ پس API مشترک برای چند برنامه، معیارِ طراحی می‌شود.

The agreed workshop scope is a reusable developer platform, so shared APIs across applications become a design criterion.

## فرض‌ها / Assumptions

هنوز تعداد توسعه‌دهندگان، نوع برنامه و نیاز سازمانی تأیید نشده‌اند.

Developer count, application types, and organizational requirements remain unconfirmed.

## روش آزمون / Validation

دو برنامهٔ متفاوت با همان API ثبت و اجرا شوند، بدون تغییر هسته.

Register and run two different applications through the same API without core changes.

## بازنگری / Revisit

اگر مخاطب یا کاربرد اولیه عوض شد، ADR تازه ثبت شود و این تصمیم superseded شود.

If the audience or initial use case changes, supersede this record with a new ADR.
