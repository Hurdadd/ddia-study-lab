# ADR-001 — کاربر اصلی چه کسی است؟

Who is the primary user?

Status: accepted · Date: 2026-10-15

## مسئله / Context

«پلتفرم AI» می‌تواند محصولِ توسعه‌دهنده باشد، می‌تواند هم پشت‌صحنهٔ یک دستیار on-call بنشیند. این دو، نیاز و اولویت متفاوت دارند.

An AI platform can serve developers, and it can also sit behind an on-call assistant. Their needs and priorities differ.

## گزینه‌ها / Alternatives

توسعه‌دهندهٔ برنامهٔ AI؛ یا مهندس on-call.

AI-application developers or on-call engineers.

## انتخاب فعلی / Choice

کاربر اصلی نسخهٔ اول، توسعه‌دهنده است؛ Investigator هم فقط یک برنامهٔ نمونهٔ روی پلتفرم می‌ماند.

For the first version, the primary user is the application developer; Investigator stays one sample app on the platform.

## چرایی و trade-off / Rationale and trade-off

دامنهٔ پذیرفته‌شدهٔ این کارگاه، پلتفرمِ قابل‌استفاده‌مجدد برای توسعه‌دهنده است؛ پس API مشترک برای چند برنامه می‌شود معیارِ طراحی.

The agreed workshop scope is a reusable developer platform, so a shared API across applications becomes a design criterion.

## فرض‌ها / Assumptions

تعداد توسعه‌دهندگان، نوع برنامه و نیاز سازمانی هنوز تأیید نشده‌اند.

Developer count, application types, and organizational requirements are still unconfirmed.

## روش آزمون / Validation

دو برنامهٔ متفاوت با همان API ثبت و اجرا می‌شوند، بدون هیچ تغییری در هسته.

Register and run two different applications through the same API, with no core changes.

## بازنگری / Revisit

اگر مخاطب یا کاربرد اولیه عوض شد، یک ADR تازه ثبت می‌کنیم و این تصمیم superseded می‌شود. یادت باشه.

If the audience or initial use case changes, we supersede this record with a new ADR. Remember that.
