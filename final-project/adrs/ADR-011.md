# ADR-011 — چرا انتشار باید از gate ارزیابی بگذرد؟

Why gate release promotion on evaluation?

Status: proposed · Date: 2026-10-15

## مسئله / Context

prompt جدید می‌تونه یه خانوادهٔ task رو بهتر و یه خانوادهٔ دیگه رو بدتر کنه.

A new prompt can improve one task family and wreck another.

## گزینه‌ها / Alternatives

دموی دستی؛ تنها LLM judge؛ مجموعهٔ ترکیبی و holdout نسخه‌دار.

Manual demos, only an LLM judge, or mixed evaluation on versioned holdouts.

## انتخاب فعلی / Choice

manifest ثابت، چند trial، state check و judge کالیبره؛ promotion با CAS و canary.

A pinned manifest, a few trials, state checks and a calibrated judge, and a promotion through CAS and canary.

## چرایی و trade-off / Rationale and trade-off

نتیجهٔ قابل‌تکرار از متنِ قشنگ مهم‌تر است؛ معیار و threshold باید پیش از دیدن نتیجه تعیین بشن.

Reproducible outcomes matter more than prose; set criteria and thresholds before seeing results.

## فرض‌ها / Assumptions

اندازهٔ dataset و حداقل بهبود هنوز تصمیم نشده؛ ۱۰۰٪ موفقیت روی نمونهٔ کوچک تعمیم نداره.

The dataset size and the minimum improvement are still undecided; 100% on a small sample doesn't generalize.

## روش آزمون / Validation

regression عمدی؛ scorer drift؛ leakage؛ هزینهٔ همهٔ attemptها؛ و rollback روی canary.

Injected regression, scorer drift, leakage, the cost of every attempt, and a rollback on the canary.

## بازنگری / Revisit

task جدید یا model revision جدید، coverage و threshold را بازبینی می‌کنه. آستانه را بعد از دیدن نتیجه جابه‌جا نکن.

A new task or a new model revision sends coverage and thresholds back for review. Don't move the threshold after you've seen the result.
